# CHONG ADVENTURE (React + Vite + Tailwind + Framer Motion)

    npm install
    npm run dev
    npm run build

Photos: add JPGs to `public/images/` using the names in `src/data/*.js`
(`hero.jpg`, `serengeti.jpg`, `serengeti-1.jpg` … `-3.jpg`, `kilimanjaro.jpg`, etc.).
Until a file exists, a gradient placeholder shows. All content lives in `src/data/`.
